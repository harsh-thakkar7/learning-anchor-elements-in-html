# Learning Anchor Elements in HTML

An HTML project demonstrating how to use anchor (`<a>`) elements to create hyperlinks. Features a top 5 favourite websites list with clickable links.

## What You'll Learn

- Creating hyperlinks with the `<a>` tag
- Using the `href` attribute
- Opening links in the browser
- Ordered lists with anchor elements

## How to Run

1. Clone this repository
2. Open `index.html` in your browser
